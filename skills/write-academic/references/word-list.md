# Word list for academic writing

This list gives plain swaps for the long words, stock phrases and hype that make academic text hard to read. It is not complete, and the rule matters more than the list: if a shorter, more common word has the same meaning, use it.

Technical terms are not on this list. If a word has an exact meaning in the field, such as "optimal", "robust" in statistics or "significant" with a test, keep it and use it only in that meaning. The "Use" column then says how to check the use, not what to swap it for.

`scripts/check.py` reads the tables in this file, so keep each table in two columns with one entry in each row.

## Contents

- Long words
- Wordy phrases
- Stock figures of speech
- Hype and filler
- Weak connecting words

## Long words

| Avoid | Use |
|---|---|
| ascertain | find, determine |
| commence | start, begin |
| endeavor | try, attempt |
| endeavour | try, attempt |
| facilitate | help, allow, make possible |
| functionality | function, feature |
| methodology | method (keep "methodology" for the study of methods) |
| modification | change |
| necessitate | need, require |
| numerous | many |
| possess | have |
| terminate | end, stop |
| utilization | use |
| utilize | use |

## Wordy phrases

| Avoid | Use |
|---|---|
| a majority of | most |
| at the present time | now, currently |
| due to the fact that | because |
| for the purpose of | to, for |
| has been shown to be | is (and cite the source) |
| in light of | given, because of |
| in order to | to |
| in the case of | for, in |
| in the context of | in, for |
| in terms of | (rewrite and name the measure) |
| it is important to note that | (cut) |
| it is interesting to note that | (cut) |
| it is worth noting that | (cut) |
| it should be noted that | (cut) |
| on the basis of | from, based on |
| plays a crucial role | (say what it does) |
| plays a key role | (say what it does) |
| plays a pivotal role | (say what it does) |
| prior to | before |
| serves as | is, acts as |
| subsequent to | after |
| the fact that | that |
| with regard to | about, for |

## Stock figures of speech

| Avoid | Use |
|---|---|
| a growing body of literature | (cite the studies) |
| at the forefront of | leading |
| bridge the gap | connect, close the gap between X and Y |
| cornerstone | basis |
| double-edged sword | has costs and benefits |
| holy grail | main goal |
| landscape | field, set of methods |
| paves the way | allows, makes possible |
| piece of the puzzle | (say what it explains) |
| push the boundaries | extend |
| sheds light on | shows, explains |
| tapestry | (say what the parts are) |
| unlock the potential | allow, make possible |

## Hype and filler

| Avoid | Use |
|---|---|
| clearly | (cut, and show the evidence) |
| comprehensive | (check that it is complete, or write "broad") |
| delve | study, examine |
| groundbreaking | (cut, and give the result) |
| harness | use |
| intricate | complex |
| it is well known that | (cite the source) |
| leverage | use |
| multifaceted | (name the parts) |
| myriad | many |
| novel | new (or say what is new) |
| nuanced | (say what the nuance is) |
| obviously | (cut, and show the evidence) |
| pivotal | important, central |
| plethora | many |
| realm | field, area |
| remarkable | (cut, and give the number) |
| remarkably | (cut, and give the number) |
| revolutionary | (cut, and give the result) |
| seamless | (say what works without extra steps) |
| showcase | show |
| significant | (use only with a statistical test, or write "large") |
| significantly | (use only with a statistical test, or write "greatly") |
| underscore | show, confirm |
| unprecedented | (say what it is compared with) |

## Weak connecting words

| Avoid | Use |
|---|---|
| additionally | also |
| furthermore | also |
| hence | so, therefore |
| moreover | also |
| notwithstanding | despite |
| whereby | by which |
