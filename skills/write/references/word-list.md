# Word list

Use this list to find short, plain words for common long or stale ones. The list is not complete. The rule is more important than the list: if a shorter, more common word has the same meaning, use it.

The "Use" column gives the usual swap. Sometimes the best swap is to cut the word or to rewrite the sentence. Sometimes the word in the "Avoid" column is the only exact word. Then keep it (Orwell's rule 6).

`scripts/check.py` reads the tables in this file. Keep each table in two columns, with one entry for each row.

## Contents

- Long words
- Wordy phrases
- Stock figures of speech
- Jargon and foreign phrases
- Weak connecting words
